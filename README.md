# Torchlight of Building

An unofficial, fan-made build planner and damage calculator for **Torchlight: Infinite** (SS14 Tartarus).

> **Calculations are a work in progress.** Many mechanics are modeled, but some are only partly modeled or not modeled yet. Every tooltip line has a badge (*In calc*, *Not modeled*, and so on), so you can see what is counted. Treat the figures as estimates, not exact in-game numbers.

## ⭐ Import from game

If the game is installed on the same PC, one click imports the last character you logged into: gear, talents, skills, hero, pacts and more, all read from the game's local log.

**Nothing is sent anywhere.** The import only reads files on your own PC.

## Features

- Hero traits and trait trees
- Talents, prisms and slates
- Skill board with supports
- Gear crafting (rare, legendary, Vorax)
- Pactspirits and kismets
- Followers
- Damage paths and dummy recount
- Effective HP
- Build library with export / import codes
- Ctrl + F search
- Built-in update check

## Install and update

Download the latest version from the **[Releases page](https://github.com/TomSelleck09/Torchlight-of-Building-Releases/releases/latest)**. There are two options:

- **Installer** (`TLI-Build-Planner-Setup-0.2.0.exe`), recommended. It updates itself from inside the app.
- **Portable** (`TLI-Build-Planner-0.2.0-portable.exe`), no install needed. The app tells you when a new version is out and opens this page.

**Windows SmartScreen:** the app isn't code-signed, so the first launch shows "Windows protected your PC". Click **More info → Run anyway**.

**Updating**

- **Installer:** the app checks for updates when it starts, and from **Help → Check for updates**. It then downloads the update and restarts.
- **Portable:** download the new exe from the Releases page.

**Requirements**

- Windows 10 or 11, 64-bit
- Import from game needs the game installed on the same PC
