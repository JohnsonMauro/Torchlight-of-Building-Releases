    Import from game

    Read from the game's log folder on this computer by the planner. Only build data is kept; nothing is uploaded or stored.

    Pick UE_game.log from <Torchlight Infinite>\UE_game\TorchLight\Saved\Logs (with Steam, by default C:\Program Files (x86)\Steam\steamapps\common\Torchlight Infinite\UE_game\TorchLight\Saved\Logs). The game writes your build to it each time you log in to a character.

    The log is read in this browser only. It is not uploaded or stored.
